# CrediManager APK

Aqui vive solo el instalador de la app movil de CrediManager (sin codigo).

Descarga: https://github.com/xM1KeManx/credimanager-apk/raw/main/CrediManager.apk

El archivo siempre se llama CrediManager.apk y se reemplaza en cada version, para que el enlace no cambie.
Al abrirlo en Android hay que permitir instalar apps desconocidas la primera vez.
